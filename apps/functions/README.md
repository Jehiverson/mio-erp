# Firebase Functions · Fase 3

Dos callables de segunda generación: saveInventoryProduct y analyzeInventoryProduct. Runtime Node22. Compilar desde raíz con npm run build --workspace @hackaton/functions. El resultado incluye contratos compartidos bajo lib; main apunta a lib/apps/functions/src/index.js.

Autenticación, membresía y App Check obligatorios en producción. QWENCLOUD_API_KEY es un secreto; parámetros públicos de servidor en .env.example. Ver docs/04-firebase-qwen-fase3.md en la raíz. No hay despliegue realizado.
